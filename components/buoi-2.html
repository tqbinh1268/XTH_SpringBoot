Buổi 2: REST Controller Cơ Bản & Thao Tác Dữ Liệu Tạm Thời (In-Memory)

2.1 Tóm tắt Lý thuyết & Kiến thức Cốt lõi

RESTful API thiết lập thiết kế định vị tài nguyên bằng danh từ số nhiều quy ước công khai và thực hiện thao tác tác động trực tiếp thông qua 4 giao thức HTTP chính xác: GET (Đọc dữ liệu), POST (Khởi tạo mới), PUT (Sửa đổi toàn bộ), và DELETE (Xóa bỏ).

2.2 Hướng dẫn thực hành từng bước (Step-by-Step)

Bước 1: Thiết kế mô hình lớp thực thể lưu trữ đối tượng (Model)

Tạo một package mới mang tên com.fpoly.lab.model. Khởi tạo tệp tin Product.java ứng dụng Lombok:

Java
package com.fpoly.lab.model;

import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;

@Data
@NoArgsConstructor
@AllArgsConstructor
public class Product {
    private Long id;
    private String name;
    private Double price;
}
Bước 2: Triển khai ProductController xử lý API tuần hoàn CRUD (Phiên bản ban đầu)

Tạo một Class Java mới mang tên ProductController.java đặt trong gói controller. Lưu ý: Chúng ta sẽ refactor class này ở Buổi 3.

Java
package com.fpoly.lab.controller;

import com.fpoly.lab.model.Product;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import java.util.ArrayList;
import java.util.List;

@RestController
@RequestMapping("/api/products")
public class ProductController {

    private final List productList = new ArrayList<>();

    public ProductController() {
        productList.add(new Product(1L, "Laptop Acer Nitro", 18500000.0));
        productList.add(new Product(2L, "Chuột Logitech G102", 400000.0));
    }

    @GetMapping
    public ResponseEntity> getAllProducts() {
        return ResponseEntity.ok(productList);
    }

    // Các phương thức CRUD khác...
}
Bước 3: Hướng dẫn cấu hình kiểm thử dữ liệu qua phần mềm Postman

Để test tính năng thêm mới POST: Chọn phương thức hành động tương ứng trong Postman, điền đường link http://localhost:8081/api/products. Chuyển sang thẻ Body → chọn mục định dạng thô raw → chọn kiểu dữ liệu cấu trúc JSON và truyền dữ liệu mẫu sau:

JSON
{
    "id": 3,
    "name": "Bàn phím cơ AKKO",
    "price": 1250000.0
}

Bấm chọn nút Send kiểm tra mã trạng thái góc màn hình phản hồi chuẩn 201 Created.

Test Nhanh (Import thẳng vào Postman hoặc chạy cURL)

Bạn có thể copy đoạn mã cURL sau và dán trực tiếp vào mục Import → Raw text trong Postman để có ngay Request hoàn chỉnh:

cURL (POST)
curl --location 'http://localhost:8081/api/products' \
--header 'Content-Type: application/json' \
--data '{
    "id": 3,
    "name": "Bàn phím cơ AKKO",
    "price": 1250000.0
}'
cURL (GET)
curl --location 'http://localhost:8081/api/products'

Bài tập rèn luyện nâng cao về nhà

  • Bổ sung endpoint GET /api/products/top?n=5 trả về 5 sản phẩm nổi bật.
  • Bổ sung endpoint GET /api/products/statistics trả về thống kê: tổng số, giá trung bình, cao nhất, thấp nhất.
  • Tạo collection Postman lưu lại các request đã test, export ra file JSON và đẩy lên GitHub.

Tiêu chí đánh giá

  • Đầy đủ 6 endpoint cơ bản, hoạt động đúng (5 điểm).
  • 2 endpoint nâng cao trả đúng dữ liệu (3 điểm).
  • Có file Postman collection được commit cùng source code (2 điểm).
