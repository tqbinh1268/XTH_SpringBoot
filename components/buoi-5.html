Buổi 5: Thiết Lập Mối Quan Hệ Thực Thể, Phân Trang & Sắp Xếp Dữ Liệu

5.1 Tóm tắt Lý thuyết & Kiến thức Cốt lõi

Bài toán liên kết thực thể Một - Nhiều diễn ra phổ biến (Một Danh mục chứa Nhiều Sản phẩm). Cần đặc biệt ưu tiên cấu hình cơ chế nạp dữ liệu trì hoãn FetchType.LAZY nhằm ngăn chặn hiện tượng nghẽn băng thông và lỗi truy vấn hệ thống nghiêm trọng.

5.2 Hướng dẫn thực hành từng bước (Step-by-Step)

Bước 1: Thiết lập tạo lớp thực thể cha Danh mục (Category)

Khởi tạo một Class mới mang tên `Category.java` đặt trong gói thư mục `model` định nghĩa mối quan hệ:

Java
package com.fpoly.lab.model;

import jakarta.persistence.*;
import lombok.Data;
import java.util.List;

@Data
@Entity
@Table(name = "categories")
public class Category {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String categoryName;

    // mappedBy: Trỏ chính xác tới tên của biến khai báo nằm bên trong lớp con (ProductDb)
    @OneToMany(mappedBy = "category", cascade = CascadeType.ALL, fetch = FetchType.LAZY)
    private List products;
}

Bổ sung thêm khóa ngoại liên kết thuộc tính sau vào bên trong thân Class con ProductDb.java:

Java
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "category_id") // Tạo cột khóa ngoại ánh xạ trực tiếp dưới bảng MySQL Database
    private Category category;

Bước 3: Tiếp nhận tham số động kiểm thử phân trang tại Controller

Cập nhật bổ sung Endpoint động tiếp nhận Query String từ Client gửi lên vào lớp điều phối ProductDbController.java:

Java
    @GetMapping("/page")
    public ResponseEntity> getProductsPage(
            @RequestParam(defaultValue = "0") int page,
            @RequestParam(defaultValue = "5") int size,
            @RequestParam(defaultValue = "id") String sortBy) {
        return ResponseEntity.ok(productDbService.getProductsWithPagination(page, size, sortBy));
    }

*Nghiệm thu thực tế:* Truy cập kiểm thử qua trình duyệt theo mẫu liên kết sau để xem dữ liệu cấu trúc metadata phân trang hoàn chỉnh: http://localhost:8081/db/products/page?page=0&size=2&sortBy=price

Bài tập rèn luyện nâng cao về nhà

  • Hoàn thiện đầy đủ các API quan hệ Category - Product (hoặc Class - Student).
  • Viết @Query đếm số lượng sản phẩm theo từng danh mục.
  • Đọc tài liệu về N+1 query problem và viết giải thích ngắn (200 từ) về cách phát hiện và xử lý.

Tiêu chí đánh giá

  • Quan hệ entity được thiết lập đúng, tạo bảng có khóa ngoại (3 điểm).
  • API quan hệ trả đúng dữ liệu (3 điểm).
  • Pagination hoạt động đúng, có metadata (2 điểm).
  • Có @Query JPQL chạy đúng (2 điểm).
