D. Phụ Lục: Tài Liệu Tham Khảo & Lộ Trình

1. Tổng Hợp Các Lệnh cURL / Postman (Phục vụ Test Nhanh)

Dưới đây là các lệnh cURL hoàn chỉnh cho toàn bộ các thao tác CRUD. Bạn có thể copy và dán trực tiếp vào Terminal, hoặc dùng tính năng Import (Paste Raw Text) trong Postman để sinh ra request tự động.

Luồng In-Memory (Sử dụng List/ArrayList)

1. Lấy danh sách sản phẩm (GET)
curl --location 'http://localhost:8081/api/products'
2. Lấy 1 sản phẩm theo ID (GET)
curl --location 'http://localhost:8081/api/products/1'
3. Thêm mới (POST)
curl --location 'http://localhost:8081/api/products' \
--header 'Content-Type: application/json' \
--data '{
    "id": 3,
    "name": "Bàn phím cơ AKKO",
    "price": 1250000.0
}'
4. Cập nhật sản phẩm (PUT)
curl --location --request PUT 'http://localhost:8081/api/products/1' \
--header 'Content-Type: application/json' \
--data '{
    "id": 1,
    "name": "Laptop Acer Nitro (Đã cập nhật)",
    "price": 19000000.0
}'
5. Xóa sản phẩm (DELETE)
curl --location --request DELETE 'http://localhost:8081/api/products/1'

Luồng Database (Sử dụng MySQL + JPA)

1. Lấy danh sách (GET)
curl --location 'http://localhost:8081/db/products'
2. Lấy 1 sản phẩm theo ID (GET)
curl --location 'http://localhost:8081/db/products/1'
3. Thêm mới (POST - Hợp lệ)
curl --location 'http://localhost:8081/db/products' \
--header 'Content-Type: application/json' \
--data '{
    "name": "Màn hình Dell 24 inch",
    "price": 3200000.0
}'
4. Test Lỗi Validation (POST - Thiếu Name, Giá âm)
curl --location 'http://localhost:8081/db/products' \
--header 'Content-Type: application/json' \
--data '{
    "name": "",
    "price": -500.0
}'
5. Cập nhật sản phẩm (PUT)
curl --location --request PUT 'http://localhost:8081/db/products/1' \
--header 'Content-Type: application/json' \
--data '{
    "name": "iPhone 15 Pro Max (Đã giảm giá)",
    "price": 33990000.0
}'
6. Xóa sản phẩm (DELETE)
curl --location --request DELETE 'http://localhost:8081/db/products/1'
7. Phân trang (GET)
curl --location 'http://localhost:8081/db/products/page?page=0&size=2&sortBy=price'

3. Lộ trình phát triển sự nghiệp từ Spring Boot Core

Hoàn thành khóa học này là bước khởi đầu vững chắc. Để trở thành một lập trình viên Java chuyên nghiệp và toàn diện, hãy chinh phục các đỉnh cao tiếp theo:

  • Hoàn thiện Giao diện Người dùng (Frontend): Nâng tầm sản phẩm bằng cách xây dựng một Single Page Application (SPA) hiện đại với VueJS hoặc React, kết nối và tiêu thụ toàn bộ hệ thống API bạn vừa xây dựng. Đây là bước đi tất yếu để trở thành một Full-stack Developer.
  • Bảo mật chuyên sâu với Spring Security: Làm chủ "người gác cổng" Spring Security, triển khai xác thực và phân quyền bằng JWT (JSON Web Tokens) để bảo vệ tài nguyên hệ thống một cách chuyên nghiệp.
  • Kiểm thử Tích hợp & Tự động hóa: Nâng cao chất lượng mã nguồn với Integration Test (@SpringBootTest) và ảo hóa môi trường test bằng TestContainers, đảm bảo ứng dụng chạy ổn định trong mọi kịch bản.
  • Giám sát và Tối ưu hóa Hiệu năng: Sử dụng Spring Boot Actuator để theo dõi "sức khỏe" ứng dụng và triển khai Caching với Redis để tăng tốc độ phản hồi, giảm tải cho database.
  • Kiến trúc Microservices: Phá vỡ ứng dụng nguyên khối (monolith) thành các dịch vụ nhỏ, độc lập (microservices) bằng Spring Cloud, làm quen với Service Discovery, API Gateway và hàng đợi tin nhắn (RabbitMQ/Kafka).
  • Vận hành & Triển khai liên tục (CI/CD): Tự động hóa hoàn toàn quy trình build, test và deploy ứng dụng lên môi trường production bằng GitHub Actions hoặc GitLab CI, rút ngắn thời gian phát hành sản phẩm.
