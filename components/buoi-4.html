Buổi 4: Luồng Database Song Song Với Spring Data JPA (P1)

4.1 Tóm tắt Lý thuyết & Kiến thức Cốt lõi

Spring Data JPA là giải pháp công nghệ bọc trừu tượng (Wrapper) nằm phía trên JPA tiêu chuẩn, ứng dụng sức mạnh của Hibernate framework để triển khai kỹ nghệ ánh xạ thực thể ORM (Object-Relational Mapping) thông minh.

Lưu ý quan trọng: Để giữ nguyên bài thực hành In-Memory phục vụ ôn tập, chúng ta sẽ thiết kế một luồng API song song hoàn toàn mới có hậu tố `Db` thay vì ghi đè lên code cũ.

4.2 Hướng dẫn thực hành từng bước (Step-by-Step)

Bước 1: Chuẩn bị cơ sở dữ liệu trống trên hệ quản trị MySQL

Mở ứng dụng MySQL Workbench truy cập máy chủ phòng máy, tạo cơ sở dữ liệu mới hỗ trợ font tiếng Việt:

SQL
CREATE DATABASE fpoly_spring_core CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
Bước 2: Bổ sung Driver kết nối dữ liệu vào file điều phối quản lý tài nguyên pom.xml

Chèn thêm đoạn mã cấu hình dependencies sau vào bên trong tệp tin pom.xml:

XML
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>

*Chú ý bắt buộc:* Nhấp chọn nút lệnh biểu tượng vòng xoay **Reload All Maven Projects** ở góc phải màn hình IntelliJ để ép buộc hệ thống tải file thư viện về.

Bước 3: Định cấu hình khai báo chuỗi liên kết DataSource liên thông

Mở file thuộc tính hệ thống src/main/resources/application.properties và cập nhật cấu hình tài khoản kết nối cụ thể:

Properties

spring.datasource.username=root
spring.datasource.password=ThayMatKhauCuaBanVaoDay

# Kích hoạt tính năng Hibernate tự quét sinh bảng hoặc cập nhật cấu trúc cột tự động từ mã Java
spring.jpa.hibernate.ddl-auto=update
# Giữ cho Spring Boot trì hoãn khởi tạo dữ liệu SQL cho đến khi Hibernate đã tạo bảng xong

# Ép buộc in rõ câu lệnh SQL chạy ngầm xuống màn hình để theo dõi debug
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
Bước 3.1: Tạo kịch bản dữ liệu demo cho Buổi 4 / Buổi 5

Chuẩn bị dữ liệu mẫu cho hai bảng có quan hệ thật sự: categories và products.

SQL
-- 1. Tạo database nếu chưa tồn tại và chuyển sang database đó
CREATE DATABASE IF NOT EXISTS fpoly_spring_core CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE fpoly_spring_core;

-- 2. Tạo bảng categories
CREATE TABLE IF NOT EXISTS categories (
    id INT AUTO_INCREMENT PRIMARY KEY,
    category_name VARCHAR(100) NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 3. Tạo bảng products (tham chiếu tới categories)
CREATE TABLE IF NOT EXISTS products (
    id INT AUTO_INCREMENT PRIMARY KEY,
    product_name VARCHAR(255) NOT NULL,
    description TEXT,
    price DECIMAL(12,2) NOT NULL DEFAULT 0.00,
    category_id INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_products_category FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

Bước 4: Tạo Model Entity MỚI cho luồng Database

Để giữ nguyên luồng In-Memory, chúng ta sẽ KHÔNG sửa đổi class Product. Thay vào đó, ta tạo một class mới là ProductDb.java trong gói model để ánh xạ với bảng trong cơ sở dữ liệu.

Java
package com.fpoly.lab.model;

import jakarta.persistence.*;
import lombok.Data;
import lombok.NoArgsConstructor;
import lombok.AllArgsConstructor;

@Data
@NoArgsConstructor
@AllArgsConstructor
@Entity
@Table(name = "products")
public class ProductDb {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "product_name", nullable = false, length = 150)
    private String name;

    @Column(nullable = false)
    private Double price;
}
Bước 5: Tạo Repository MỚI cho luồng Database

Tạo một interface mới là ProductDbRepository.java trong gói repository. Interface này sẽ kế thừa JpaRepository và làm việc với entity ProductDb.

Java
package com.fpoly.lab.repository;

import com.fpoly.lab.model.ProductDb;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;
import java.util.List;

@Repository
public interface ProductDbRepository extends JpaRepository {

    // Kỹ thuật Derived Query: Spring tự động phân rã tên hàm biên dịch ra câu lệnh truy vấn SQL tương ứng
    List findByName(String name);
    List findByPriceGreaterThan(Double price);
}

Khởi chạy lại dự án, kiểm tra MySQL Workbench sẽ thấy bảng products được tự động sinh ra (hoặc cập nhật) một cách hoàn chỉnh dựa trên entity ProductDb.

Bước 6: Hoàn thiện luồng Database với Service và Controller riêng

Để tách biệt hoàn toàn, chúng ta sẽ tạo Service và Controller mới cho luồng Database.

6.1. Tạo ProductDbService

Trong gói service, tạo class ProductDbService.java. Class này sẽ làm việc với ProductDbRepository.

Java
package com.fpoly.lab.service;

import com.fpoly.lab.model.ProductDb;
import com.fpoly.lab.repository.ProductDbRepository;
import org.springframework.stereotype.Service;
import java.util.List;
import java.util.Optional;

@Service
public class ProductDbService {
    private final ProductDbRepository productDbRepository;

    public ProductDbService(ProductDbRepository productDbRepository) {
        this.productDbRepository = productDbRepository;
    }

    public List getAllProducts() {
        return productDbRepository.findAll();
    }

    public Optional getProductById(Long id) {
        return productDbRepository.findById(id);
    }

    public ProductDb addProduct(ProductDb product) {
        return productDbRepository.save(product);
    }
}

6.2. Tạo ProductDbController

Trong gói controller, tạo class ProductDbController.java. Controller này sẽ là điểm truy cập cho các API liên quan đến database, sử dụng một đường dẫn (endpoint) khác để phân biệt.

Java
package com.fpoly.lab.controller;

import com.fpoly.lab.model.ProductDb;
import com.fpoly.lab.service.ProductDbService;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import java.util.List;
import java.util.Optional;

@RestController
@RequestMapping("/db/products") // Endpoint riêng cho luồng DB
public class ProductDbController {
    private final ProductDbService productDbService;

    public ProductDbController(ProductDbService productDbService) {
        this.productDbService = productDbService;
    }

    @GetMapping
    public ResponseEntity> getProducts() {
        return ResponseEntity.ok(productDbService.getAllProducts());
    }

    @PostMapping
    public ResponseEntity saveProduct(@RequestBody ProductDb product) {
        return ResponseEntity.ok(productDbService.addProduct(product));
    }
}

Bây giờ, bạn có hai bộ API song song:

  • /api/products: Thao tác với dữ liệu In-Memory (Sử dụng Product, ProductService).
  • /db/products: Thao tác với dữ liệu trong MySQL (Sử dụng ProductDb, ProductDbService).

Bài tập rèn luyện nâng cao về nhà

  • Viết các derived query: findByNameContaining (tìm theo tên có chứa từ khóa), findBySoTinChiGreaterThan (lọc theo số tín chỉ).
  • Insert sẵn 10 record mẫu vào database (dùng file SQL hoặc CommandLineRunner).
