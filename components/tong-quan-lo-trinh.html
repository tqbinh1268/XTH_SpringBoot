B. Tổng Quan Lộ Trình 8 Buổi Học

Bảng dưới đây tóm tắt nội dung trọng tâm và kết quả đầu ra (Output) mong đợi bắt buộc của từng buổi thực hành:

Buổi Chủ đề chính Nội dung trọng tâm Output buổi học
1 Khởi động Spring Boot Ôn tập Java nhanh, giới thiệu Spring/Spring Boot, Tour Spring Initializr, phân tích cấu trúc dự án. + Chia nhóm & chọn chủ đề dự án.
+ Hello World REST chạy ổn định trên trình duyệt.
2 REST Controller cơ bản HTTP methods, các tập hợp annotation ánh xạ Mapping, ResponseEntity, viết Postman Collection kiểm thử. Hoàn thành CRUD API trên dữ liệu tạm thời in-memory cho thực thể Đối tượng Sản phẩm (Product).
3 DI & Kiến trúc 3 lớp Cơ chế kiểm soát IoC, Bean, các stereotype annotation, tách ba tầng Controller - Service - Repository, viết Unit Test. Mã nguồn dự án được tổ chức phân tầng rõ ràng, triển khai thành công 1-2 unit test mẫu.
4 Spring Data JPA - P1 Khái niệm ORM, cấu hình Entity, khóa Id, cột Column, JpaRepository, kết nối H2 và cơ sở dữ liệu MySQL thật. Xóa dữ liệu in-memory, hoàn thiện tính năng CRUD ghi/đọc dữ liệu trực tiếp xuống MySQL.
5 Spring Data JPA - P2 Thiết lập mối quan hệ thực thể OneToMany/ManyToOne, fetch type (LAZY/EAGER), cú pháp JPQL, Phân trang và Sắp xếp. API hỗ trợ liên kết thực thể cha-con, phản hồi dữ liệu phân trang kèm metadata điều hướng.
6 Validation & Exception Ứng dụng Bean Validation, từ khóa @Valid, xử lý ngoại lệ tập trung bằng ControllerAdvice, chuẩn hóa response lỗi. Hệ thống chống được dữ liệu rác đầu vào, trả cấu trúc thông báo lỗi JSON đồng bộ, tinh gọn.
7 DTO & Configuration Tách biệt dữ liệu qua lớp bọc DTO, cơ chế Mapping, ghi nhật ký SLF4J, quản lý môi trường linh hoạt qua profiles yml. Project nâng cao tính bảo mật an toàn thông tin, tự động ghi log ra file cứng, tách biệt cấu hình dev/prod.
8 Mini Project & Deploy Hoàn thiện sản phẩm cuối khóa, hướng dẫn đóng gói build JAR, thiết lập file Dockerfile, thực thi deploy môi trường đám mây. Sản phẩm hoàn thiện vận hành trực tuyến trên internet, cấp phát URL công khai cho giảng viên chấm điểm.
