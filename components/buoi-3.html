Buổi 3: Dependency Injection & Kiến Trúc Thiết Kế Phân Tầng 3 Lớp

3.1 Tóm tắt Lý thuyết & Kiến thức Cốt lõi

Việc viết dồn toàn bộ mã nguồn xử lý logic nghiệp vụ và lưu trữ vào duy nhất file Controller vi phạm nghiêm trọng nguyên lý đơn nhiệm diện rộng. Kiến trúc 3-Tier Architecture phân rã tách biệt dự án thành các lớp độc lập: Controller (Giao tiếp), Service (Thuật toán Nghiệp vụ), và Repository (Truy xuất Kho dữ liệu).

3.2 Hướng dẫn thực hành từng bước (Step-by-Step)

Bước 1: Triển khai thiết kế cô lập tầng quản lý dữ liệu Repository

Tạo một gói package mới mang tên com.fpoly.lab.repository. Khởi tạo một Class Java mang tên ProductRepository.java:

Java
package com.fpoly.lab.repository;

import com.fpoly.lab.model.Product;
import org.springframework.stereotype.Repository;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;

@Repository // Đăng ký Class này thành một Spring Bean chịu trách nhiệm quản lý kho dữ liệu của hệ thống
public class ProductRepository {
    private final List list = new ArrayList<>();

    public ProductRepository() {
        list.add(new Product(1L, "Sách Java core", 150000.0));
    }

    public List findAll() { return list; }
    public Optional findById(Long id) {
        return list.stream().filter(p -> p.getId().equals(id)).findFirst();
    }
    public void save(Product product) { list.add(product); }
    public boolean deleteById(Long id) { return list.removeIf(p -> p.getId().equals(id)); }
}
Bước 2: Triển khai thiết kế tầng quản trị trung gian thuật toán nghiệp vụ Service

Tạo một package mới mang tên com.fpoly.lab.service. Khởi tạo một lớp Java mang tên ProductService.java:

Java
package com.fpoly.lab.service;

import com.fpoly.lab.model.Product;
import com.fpoly.lab.repository.ProductRepository;
import org.springframework.stereotype.Service;
import java.util.List;
import java.util.Optional;

@Service // Đăng ký Class này đóng vai trò tầng chứa đựng logic tính toán nghiệp vụ
public class ProductService {

    private final ProductRepository productRepository;

    // Kỹ thuật Constructor Injection bắt buộc giúp tự động nạp (tiêm) Bean phụ thuộc từ IoC Container
    public ProductService(ProductRepository productRepository) {
        this.productRepository = productRepository;
    }

    public List getAllProducts() { return productRepository.findAll(); }

    public Optional getProductById(Long id) { return productRepository.findById(id); }

    public Product addProduct(Product product) {
        if (product.getPrice() < 0) {
            throw new IllegalArgumentException("Lỗi: Giá sản phẩm bán ra thị trường không được phép mang giá trị âm");
        }
        productRepository.save(product);
        return product;
    }

    public boolean deleteProduct(Long id) { return productRepository.deleteById(id); }
}
Bước 3: Cấu trúc lại Controller phiên bản mới gọi liên kết qua Service

Mở lại file ProductController.java, xóa bỏ List nội bộ và tiêm ProductService vào:

Java
package com.fpoly.lab.controller;

import com.fpoly.lab.model.Product;
import com.fpoly.lab.service.ProductService;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;
import java.util.List;
import java.util.Optional;

@RestController
@RequestMapping("/api/products")
public class ProductController {

    private final ProductService productService;

    public ProductController(ProductService productService) {
        this.productService = productService;
    }

    @GetMapping
    public ResponseEntity> getProducts() {
        return ResponseEntity.ok(productService.getAllProducts());
    }

    @PostMapping
    public ResponseEntity saveProduct(@RequestBody Product product) {
        return ResponseEntity.ok(productService.addProduct(product));
    }
}

Bài tập rèn luyện nâng cao về nhà

  • Hoàn thiện refactor toàn bộ các hàm CRUD còn lại qua 3 lớp.
  • Viết tối thiểu 3 unit test cho ProductService: test khi tìm thấy sản phẩm, khi không tìm thấy, khi thêm mới hợp lệ.
  • Vẽ sơ đồ class diagram đơn giản (có thể vẽ tay rồi chụp ảnh) thể hiện quan hệ giữa 3 tầng.

Tiêu chí đánh giá

  • Project chia đúng 3 tầng, package gọn gàng (4 điểm).
  • Sử dụng constructor injection (không dùng @Autowired field) (2 điểm).
  • Có ít nhất 3 unit test pass thành công (3 điểm).
  • Có sơ đồ class diagram đính kèm (1 điểm).
