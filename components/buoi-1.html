Buổi 1: Khởi Động Dự Án & Hello World REST API

1.1 Tóm tắt Lý thuyết & Kiến thức Cốt lõi

Spring Boot hoạt động theo cơ chế tự động cấu hình (Auto-configuration) nhằm triệt tiêu công đoạn khai báo file XML phiền phức của Spring truyền thống. Nó nhúng sẵn ứng dụng máy chủ Tomcat bên trong, cho phép phần mềm chạy độc lập tức thì sau khi kích hoạt tệp tin thực thi.

1.2 Hướng dẫn thực hành từng bước (Step-by-Step)

Bước 1: Khởi tạo Project trên Spring Initializr

Truy cập vào trang web: start.spring.io và thiết lập cấu hình chính xác:

  • Project: Maven | Language: Java | Spring Boot: 3.3.x (Bản Stable)
  • Metadata: Group: com.fpoly | Artifact: sof3022-lab | Package: com.fpoly.lab | Java: 17
  • Dependencies: Tìm chọn đúng 3 thư viện: Spring Web, Spring Boot DevTools, và Lombok.

Bấm chọn nút GENERATE để tải về gói mã nguồn dạng nén .zip. Giải nén tệp tin và thực hiện mở import dự án bằng phần mềm IntelliJ IDEA.

Bước 2: Tạo cấu trúc Package và Class Controller đầu tiên

Trong thư mục src/main/java/com/fpoly/lab, click chuột phải tạo package mới mang tên controller. Bên trong gói này, tạo tệp mã nguồn Java HelloController.java:

Java
package com.fpoly.lab.controller;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public String sayHello() {
        return "Xin chào sinh viên FPT Polytechnic! Chúc các em học tốt Spring Boot.";
    }

    @GetMapping("/math/sum")
    public String tinhTong(@RequestParam(value = "a", defaultValue = "0") int a,
                           @RequestParam(value = "b", defaultValue = "0") int b) {
        int tong = a + b;
        return "Kết quả của " + a + " + " + b + " = " + tong;
    }
}
Bước 3: Đổi cấu hình cổng mạng hệ thống Server

Mở file tài nguyên hệ thống src/main/resources/application.properties và định cấu hình đổi port mạng tránh đụng độ:

Properties
server.port=8081
Bước 4: Chạy thử và Kiểm tra kết quả

Chuột phải vào file chứa hàm main Sof3022LabApplication.java chọn lệnh Run. Mở trình duyệt truy cập đường dẫn sau để kiểm tra kết quả:

  • http://localhost:8081/hello
  • http://localhost:8081/math/sum?a=15&b=25

Bài tập rèn luyện nâng cao về nhà

  • Tạo thêm 3 endpoint: /info (thông tin cá nhân), /time (thời gian hiện tại), /math/sum?a=5&b=3 (tổng 2 số).
  • Đẩy code lên GitHub repo cá nhân (tạo repo mới, gắn .gitignore cho Java).
  • Đọc thêm về Maven lifecycle (compile, test, package, install) và viết tóm tắt khoảng 200 từ.

Tiêu chí đánh giá

  • Project khởi chạy được, không lỗi compile (4 điểm).
  • Đủ 3 endpoint theo yêu cầu, trả đúng kết quả (4 điểm).
  • Đẩy lên GitHub đúng format, có README ngắn (2 điểm).
