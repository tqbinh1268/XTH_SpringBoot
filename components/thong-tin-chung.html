A. Thông Tin Chung Về Khóa Học

1. Mục tiêu khóa học

Sau khi hoàn thành chuỗi 8 buổi học thực chiến này, sinh viên sẽ làm chủ được các năng lực cốt lõi sau:

  • Hiểu bản chất: Định vị được Spring Boot trong hệ sinh thái Java; hiểu rõ lý do doanh nghiệp dịch chuyển sang Spring Boot thay vì Spring MVC truyền thống.
  • Khởi tạo & Cấu hình: Tự cấu hình, tổ chức quản lý dự án chuẩn thông qua Maven.
  • Kiến trúc ứng dụng: Áp dụng thuần thục kiến trúc phân tầng 3 lớp (Controller – Service – Repository) khi viết mã nguồn.
  • Thao tác dữ liệu: Làm chủ công nghệ ORM, kết nối kết xuất dữ liệu MySQL thông qua Spring Data JPA một cách tự động.
  • Hoàn thiện API chuẩn: Xây dựng hệ thống REST API tích hợp đầy đủ tính năng validation (kiểm tra dữ liệu rác) và xử lý ngoại lệ tập trung.
  • Đóng gói & Phát hành: Đóng gói ứng dụng thành tệp thực thi độc lập, ảo hóa môi trường qua Docker và deploy thành công lên internet thực tế.

2. Yêu cầu đầu vào

  • Đã hoàn thành môn Lập trình Java cơ bản (nắm chắc lập trình hướng đối tượng OOP, Exception Handling, Collections Framework, Generic, Lambda và Stream API).
  • Đã làm quen với hệ quản trị cơ sở dữ liệu quan hệ và ngôn ngữ SQL ở mức cơ bản (các lệnh SELECT, INSERT, UPDATE, DELETE và câu lệnh truy vấn JOIN).

3. Công cụ và phần mềm chuẩn bị

  • JDK 17 hoặc JDK 21 (LTS) làm môi trường biên dịch lõi.
  • IntelliJ IDEA Community Edition (hoặc bản Ultimate) hoặc Eclipse/Spring Tool Suite.
  • Maven (Được tích hợp sẵn đi kèm cùng IDE, không yêu cầu cài đặt riêng độc lập).
  • MySQL Server 8.x kết hợp giao diện trực quan MySQL Workbench hoặc DBeaver.
  • Postman (hoặc Insomnia) phục vụ công tác gửi gói request kiểm thử hệ thống API.
  • Git và tài khoản cá nhân trên nền tảng GitHub để quản lý toàn bộ kho lưu trữ source code.
